# Benchmarks

This directory is for reproducible performance measurements.

Benchmark reports should record relevant context such as:

- Hardware
- Operating system
- Driver/runtime
- Compiler and version
- Framework and version
- Model/workload
- Precision/data type
- Batch size or problem dimensions
- Warm-up procedure
- Number of repetitions
- Latency, throughput, memory use, and other relevant metrics

Avoid comparing numbers collected under materially different conditions without clearly explaining the differences.
