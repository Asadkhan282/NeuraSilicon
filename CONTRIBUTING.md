# Contributing to NeuraSilicon

Thank you for your interest in contributing to NeuraSilicon.

## What We Welcome

- GPU and AI optimization experiments
- RTL, FPGA, ASIC, and VLSI projects
- Verification and benchmarking improvements
- Semiconductor architecture research
- Technical documentation and diagrams
- Reproducible performance studies

## Contribution Workflow

1. Fork the repository.
2. Create a focused branch for your change.
3. Keep commits clear and descriptive.
4. Add documentation for new projects or experiments.
5. Include reproducible steps and results where possible.
6. Open a pull request describing what changed and why.

## Engineering Standards

- Prefer reproducible results over unsupported performance claims.
- Document hardware, software, compiler, driver, and model versions when benchmarking.
- Keep source code readable and organized.
- Never commit API keys, passwords, credentials, or private datasets.
- Cite external research, datasets, and third-party code appropriately.

## Commit Examples

- `feat: add FP4 arithmetic prototype`
- `bench: add GPU kernel latency results`
- `docs: document accelerator architecture`
- `fix: correct RTL overflow handling`

## Questions

Open a GitHub issue when a design decision, benchmark, or proposed project needs discussion.
